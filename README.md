# better-parse

[![Maven Central](https://img.shields.io/maven-central/v/com.quarkdown.better-parse/better-parse)](https://central.sonatype.com/artifact/com.quarkdown.better-parse/better-parse)

A nice parser combinator library for Kotlin JVM, JS, Wasm, Native and Multiplatform projects.

This is a fork of [h0tk3y/better-parse](https://github.com/h0tk3y/better-parse) maintained by [Quarkdown Labs](https://github.com/quarkdown-labs), adding Kotlin/Wasm support.

```groovy
dependencies {
   implementation("com.quarkdown.better-parse:better-parse:0.4.4")
}
```
